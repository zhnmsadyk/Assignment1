# Assignment1

## Description
This project demonstrates the Builder Creational Design Pattern in Java using a Pizza creation domain.

## Project Structure
- `Pizza.java` — Target product class
- `PizzaBuilder.java` — Abstract builder handling fluent setters and validation
- `ClassicPizzaBuilder.java` — Concrete builder for classic recipes
- `VegetarianPizzaBuilder.java` — Concrete builder enforcing vegetarian rules
- `PizzaDirector.java` — Director orchestrating preset configurations
- `Main.java` — Client application demonstrating usage

## How to Run
Compile and run `Main.java` using JDK 17+ or open the project in IntelliJ IDEA.
